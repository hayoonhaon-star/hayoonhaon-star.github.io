# 농촌인력중개센터 현장점검 앱 사용자 매뉴얼

## 1. 시작 전에

- **개인정보를 입력하지 않습니다.** 센터명, 담당자·근로자 이름, 연락처, 주소, 생년월일, 주민·외국인등록번호, 여권번호는 어떤 칸에도 쓰지 않습니다.
- 센터는 **점검 코드(시도-방문번호, 예: `충남-01`)** 하나로만 씁니다. 방문번호는 점검계획 일정표의 시도별 순번이며, 실원끼리 겹치지 않게 일정표에서 미리 정합니다.
- 연도·반기와 재방문 차수는 앱이 내부에서 붙이므로 따로 관리하지 않습니다.
- 기록은 **지금 쓰는 기기 안에만** 저장됩니다. 다른 사람에게 보이지 않고, 자동으로 모이지도 않습니다.
- 기기 잠금(암호·생체인증)을 반드시 켜 둡니다.

## 2. 설치

1. 앱 주소를 엽니다: `https://hayoonhaon-star.github.io/center-inspection/`
2. 홈 화면에 추가합니다.
   - iPhone·iPad: Safari 공유 버튼 → **홈 화면에 추가**
   - Android: Chrome 메뉴(⋮) → **앱 설치**
3. 한 번 연 뒤에는 인터넷이 없어도 열립니다.

## 3. 처음 화면(메뉴)

| 메뉴 | 하는 일 |
|---|---|
| 1. 점검관리 | 새 점검 만들기, 이어서 작성, 후속 점검, 삭제 |
| 2. 사전점검 | 사전제출 점검표(한글·PDF·엑셀) 불러오기·삭제, 사전자료 접수 확인, 현황·예산 입력 |
| 3. 현장점검 | 항목별 결과 입력, 지출 표본 점검(예산 집행기준 대조), 미흡 사유·현장 확인 내용·시정 권고 |
| 4. 시정조치 | 모든 미흡 사항 모음, 조치 상태 관리 |
| 5. 결과·보고서 | 자동 검증, 점검표 종합판정, 종합 의견, PDF 출력, 완료 |
| 6. 대시보드 | 점검 현황, 분야별 미흡, 조치 현황, 센터별 이력 |
| 점검기준 | 항목별 확인 기준·근거·확인서류·미흡 사유 |
| 설정·백업 | 백업 내보내기·복원, 예시 데이터, 보안 안내, 기록 삭제 |

## 4. 점검 순서

### ① 새 점검 (점검관리)
1. **+ 새 점검** → 점검 유형(농촌형/공공형), 세부유형, 운영기관 구분 선택
2. **지역(시도)** 선택, **방문번호**(일정표 순번) 입력, 점검일 확인 → **점검 만들기**
3. 화면에 점검 코드(예: `충남-01 · 2026 하반기`)가 표시됩니다. 같은 반기에 같은 코드가 이미 있으면 만들어지지 않습니다.

### ② 사전점검
1. 시·군이 보낸 **현장점검표(붙임 2·3)** 파일을 **파일 선택**으로 불러옵니다. 한글(.hwp·.hwpx), PDF, 엑셀(.xlsx) 모두 됩니다.
   - 읽은 값 목록이 먼저 나옵니다. 원본과 맞는지 확인하고 **적용**을 누릅니다.
   - 센터명·담당자·연락처·주소 칸은 읽지 않고, 원본 파일도 기기에 남기지 않습니다.
   - 불러온 기록 옆 **삭제**를 누르면 그 파일에서 채운 값이 지워집니다(직접 고친 값은 남음).
   - 배포용(보안)·암호 한글 문서, 스캔한 PDF는 읽을 수 없습니다. 일반 문서로 받거나 직접 입력합니다.
   - 칸 안에서 줄이 바뀐 PDF는 일부 값을 놓칠 수 있습니다. 빈 값은 직접 넣습니다.
2. 사전자료별로 **접수 / 미제출 / 해당없음**을 누릅니다. 미제출 서류는 현장점검에서 관련 항목에 빨간 표시로 나타납니다.
3. 엑셀이 없으면 현황·예산을 직접 입력합니다. 집행률과 센터운영비 편성비율은 자동 계산됩니다.
4. 아래 **사전 검증 결과**에서 시행지침 수치와 다른 값(전담인력 수, 작업반 인원, 편성비율 등)을 미리 확인합니다.

### ③ 현장점검
각 항목 카드에는 항목번호, 항목명, 점검 내용, **확인 기준**, 근거 쪽수, 확인 서류가 보입니다. **기준 자세히**를 누르면 판정 버튼 아래에 확인 서류·자동 검증 기준·미흡 사유가 펼쳐집니다.

1. 면담·서류 확인 후 **적정 / 미흡 / 해당없음 / 확인필요** 중 하나를 누릅니다.
2. 단가·시급·면적 등 입력칸이 있는 항목은 실제 값을 넣습니다. 시행지침 기준을 벗어나면 바로 표시됩니다.
3. **미흡**을 누르면 아래가 펼쳐집니다.
   - 미흡 사유: 여러 개 선택 가능. **기타**를 고르면 내용을 꼭 적습니다.
   - 미흡 사유는 지출 표본·수치 검증에서 확인된 것이 미리 체크됩니다.
   - 현장 확인 내용: 확인된 수치·지출 표본·사유·미제출 서류로 **자동 작성**됩니다. 고쳐 쓴 내용은 그대로 남습니다(필수).
   - 시정 권고: 고른 사유로 자동 작성됩니다. **확인 내용·권고 다시 만들기**로 자동 문안으로 되돌릴 수 있습니다.
   - 셋 중 하나라도 비어 있으면 '작성 필요' 표시가 나오고 점검을 완료할 수 없습니다.
4. 결과를 미흡에서 다른 것으로 바꾸면 입력한 내용은 보관되지만 보고서에서는 빠집니다. 다시 미흡으로 바꾸면 되살아납니다.
5. 문제없는 분야는 **미응답 항목 모두 적정**으로 한 번에 처리할 수 있습니다.
6. **예산 집행 및 회계** 분야 맨 위 **지출 표본 점검**에서 e나라도움 집행내역·지급대장의 표본을 입력합니다.
   - 표본마다 비목, 단가, 수량(교통비는 이동거리, 숙박비는 연속 참여일수 등)과 증빙 여부를 넣습니다.
   - 시행지침 집행기준과 자동 대조합니다: 교통비(1일 10·20천원), 숙박비(1박 30천원, 관외·3일 이상 연속), 간식비(1일 5천원), 신규 구직자 교육비(1인 1일 20천원, 3일, 일 100천원), 작업반장 수당(1일 10천원), 중요자산(50만원 이상) 구입, 토지·건물 등 자본 지출, 간담회(회의록·서명·사진)·임차(비교견적) 증빙, 중복 지급, e나라도움 등록·지출 증빙 누락
   - 결과는 관련 항목(A5-01~07, B4-01~04)에 연결되고, 초과·부적정 지급 추정액이 합산되어 결과 보고서에 표로 들어갑니다.
   - 표본 수는 시행지침에 기준이 없어 점검자가 정합니다.
   - 사전점검의 세부항목별 집행실적이 예산계획보다 크면 '변경 승인 확인'으로 표시됩니다.
7. 입력할 때마다 자동 저장됩니다(화면 위 '자동 저장 시:분').

### ④ 결과·보고서
1. **자동 검증 결과**를 확인합니다.
   - 기준 위반(수치 확인)·중대 사항 / 판정 불일치 / 미흡 상세 작성 미완료 / 관련 서류 미비 / 사람 확인 필요 / 미입력
   - 각 항목에 근거 쪽수와 후속 조치가 함께 나옵니다.
2. **점검표 기타 지도·점검 사항**에서 양호~매우 미흡을 고릅니다(항목 결과로 제안이 나옵니다).
3. **입력 결과로 초안 만들기**로 종합 의견 초안을 만들고 고쳐 씁니다.
4. **점검 완료**를 누릅니다. 미입력·미흡 상세 미작성이 있으면 완료되지 않습니다.
5. 보고서를 엽니다: **점검 결과 보고서 / 시정조치 요청서 / 현장점검표(붙임 2·3)** → **인쇄 · PDF 저장**
   - iPhone·iPad: 인쇄 화면에서 공유 → 'PDF로 저장'(또는 파일에 저장)
   - 출력 후 센터명·담당자·점검자 성명을 손으로 적고 서명합니다.

### ⑤ 시정조치(후속관리)
- 미흡 상세를 다 쓰면 조치 관리 대상이 됩니다. 사례는 '충남-01 · A5-04'처럼 점검 코드와 항목번호로 표시됩니다.
- 상태를 **조치 전 → 조치 중 → 조치 완료 / 재확인 필요**로 바꾸고, 조치 완료일과 확인 메모를 남깁니다.
- 같은 센터를 다시 방문할 때는 점검관리에서 **후속 점검**을 누릅니다. 같은 반기면 '충남-01 (2차)'로 붙고, 지난 미흡 사항과 조치 상태가 현장점검 화면 위에 표시됩니다.

### ⑥ 대시보드
- 연도, 유형, 점검 코드, 점검 상태, 조치 상태로 걸러 봅니다.
- 이 기기에 저장되었거나 백업으로 불러온 **실제 기록만** 집계합니다. 예시 기록은 '예시 기록 포함'을 켤 때만 들어갑니다.
- 여러 실원의 결과를 함께 보려면 각자의 백업 파일을 [설정·백업 → 백업 복원]으로 불러옵니다.

## 5. 백업 절차 (꼭 지켜 주세요)

1. 점검을 완료하면 **설정·백업 → 전체 백업(.json)** 을 누릅니다.
2. 개인정보로 보이는 형식이 있다는 안내가 나오면 **취소하고 수정**한 뒤 다시 내보냅니다.
3. 저장된 파일(다운로드 폴더)을 **원 내부 공유폴더**로 옮깁니다.
4. 기기 다운로드 폴더에 남은 백업 파일은 지웁니다.
5. 다른 실원의 백업을 불러올 때 **'번호 충돌'** 안내가 나오면, 같은 점검 코드를 서로 다른 점검에 쓴 것입니다. 일정표 번호를 확인해 한쪽을 새 번호로 다시 만듭니다.
6. 기기를 바꾸거나 기록이 사라졌으면 **백업 복원**으로 공유폴더의 파일을 불러옵니다.

> 브라우저 데이터 삭제, 앱 삭제, 기기 초기화, 오랫동안 쓰지 않는 경우 기기 안 기록이 지워질 수 있습니다. 공식 기록은 출력·서명한 점검표와 공유폴더의 백업 파일입니다.

## 6. 자주 묻는 질문

- **엑셀을 불러왔는데 일부 칸이 비어 있어요.** 양식의 노란 칸(C열)에 값이 없거나, A열 코드를 고친 경우입니다. 직접 입력하면 됩니다.
- **'판정 불일치'가 떠요.** 입력한 수치가 시행지침 기준을 벗어났거나 관련 서류가 미제출인데 '적정'을 고른 경우입니다. 증빙을 다시 확인하고 판정을 정하세요. 최종 판단은 점검자가 합니다.
- **[행정 확인 필요]는 뭔가요?** 시행지침에 세부 판단 기준(횟수·규모 등)이 없는 항목입니다. 점검자 판단으로 기록하고, 필요하면 소관 부서에 확인합니다.
- **완료한 점검을 고치고 싶어요.** 결과·보고서에서 **수정 재개**를 누릅니다.
